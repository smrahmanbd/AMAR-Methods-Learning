Methods in accident research, for beginners

Seven ideas behind modern crash-data analysis

Papers in the journal Analytic Methods in Accident Research keep returning to the same few statistical ideas. This site explains each one with an animation you can control, a calculation you can follow by hand and a picture to remember it by.

The seven ideas

Idea 1

Unobserved heterogeneity

The same variable can affect different people and places differently, for reasons the data do not record.

Memory stop: the costume shop

Idea 2

Simulated maximum likelihood

When a formula has no exact answer, draw many possible values, compute the result for each and average.

Memory stop: the dart casino

Idea 3

Endogeneity

A variable is endogenous when something unseen drives both it and the outcome, so a plain comparison is misleading.

Memory stop: the icy bridge

Idea 4

Spatial and temporal correlation

Sites that are close together, and the same site in consecutive years, share influences the data do not record.

Memory stop: gossip street

Idea 5

Temporal instability

The effect of a variable can change from one period to the next, so a model built on old years may not describe today.

Memory stop: the melting clock tower

Idea 6

Prediction versus causality

A model can forecast well without telling you what would happen if you changed something.

Memory stop: the fortune teller and the mechanic

Idea 7

Crash–conflict relationship

Near misses are far more common than crashes; with the right statistics they can be used to estimate crash risk.

Memory stop: the near-miss arcade

Start here if the mathematics is new

Logit and likelihood from zero builds the two workhorses of the field from school mathematics: probability, odds and log-odds; likelihood and log-likelihood; and the likelihood ratio test with its chi-square ruler, degrees of freedom and p-value.

Then watch restricted and unrestricted models, animated: four animations and five examples of what it means to lock a model’s parameters and test the locks.
