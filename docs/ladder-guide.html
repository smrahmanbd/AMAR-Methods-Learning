2The big picture

All four models answer the same question: given what we know about a crash, what is the probability of each injury outcome? They differ in how they treat the effect (coefficient) of a variable.

ModelFull nameThe coefficient is…What it adds
MNLMultinomial logitone fixed number for everyonethree or more unordered outcomes
RPLRandom parameters (mixed) logita distribution across crashesunobserved heterogeneity: σ
RPLHMRPL with heterogeneity in meansa distribution whose mean depends on observed Za shift: Θ
RPLHMVRPL with heterogeneity in means and variances…and whose spread depends on observed Wa stretch: ω
Four words: fixed → spread → shift → stretch. Think of a coefficient as a jelly on a table. MNL is a toothpick: a single value. RPL is a wobbly jelly: a spread of values. RPLHM slides the jelly to a new place for some crashes. RPLHMV also stretches or squeezes it.

Underneath all four sits one engine, the log-likelihood. It is used to estimate each model (find the best coefficients) and to compare them (decide whether a richer model is worth it). That is why this guide spends time on likelihood before the models.

3Probability, odds and log-odds

Probability p is a number from 0 to 1. Odds compare "happens" with "does not happen": odds = p ÷ (1 − p). Log-odds (the logit) is the natural log of the odds.

Why log-odds? p is trapped between 0 and 1, but log-odds can be any number. So it is safe to write log-odds as a straight line, β₀ + β₁x, and never predict an impossible probability.

Going back. From log-odds z: odds = ez, and p = odds ÷ (1 + odds).

4The binary logit

P(y = 1) = 1 ÷ (1 + e−z),   z = β₀ + β₁x₁ + β₂x₂ + …z is the score (log-odds); the β's are the coefficients we estimate.

Worked example. β₀ = −1, β₁ = 0.9, x = 2.

  1. Score: z = −1 + 0.9 × 2 = 0.8.
  2. Odds: e0.8 = 2.226.
  3. Probability: 2.226 ÷ (1 + 2.226) = 2.226 ÷ 3.226 = 0.690.
  4. Odds ratio for x: e0.9 = 2.46. One more unit of x multiplies the odds by 2.46.

Reading a coefficient. The sign says the direction. The size is a change in log-odds, not in probability. The t-statistic = coefficient ÷ standard error; |t| above 1.96 means the coefficient is statistically different from zero at the 5% level (two-sided).

5Likelihood and log-likelihood

Likelihood asks: if the parameters had these values, how probable would exactly the data we saw be? The data are fixed; the parameters are what we vary.

Simplest case. Ten crashes; three were severe. If each crash is severe with probability p, the probability of this pattern is

L(p) = p3 (1 − p)7    LL(p) = ln L(p) = 3 ln p + 7 ln(1 − p)
pL(p)LL(p)
0.20.001678−6.390
0.30.002224−6.109
0.40.001792−6.325
0.50.000977−6.931

Worked: p = 0.3.

  1. 0.33 = 0.027; 0.77 = 0.08235.
  2. L = 0.027 × 0.08235 = 0.002224.
  3. LL = 3 × ln 0.3 + 7 × ln 0.7 = 3 × (−1.2040) + 7 × (−0.3567) = −3.612 − 2.497 = −6.109.
Three facts to remember. (1) For discrete outcomes LL is always ≤ 0; closer to zero is better. (2) The log never moves the peak, so maximising LL and L give the same answer. (3) The peak here is at p = 3 ÷ 10: maximum likelihood picks the value that makes the observed data most probable.

Why logs? With N crashes the likelihood is a product of N probabilities, which becomes astronomically small (a computer rounds it to zero). The log turns the product into a sum: ln(P₁ × P₂ × … ) = ln P₁ + ln P₂ + … .

For a crash model with outcomes i and crashes n:

LL(β) = Σn Σi δin ln Pn(i)δin = 1 if crash n had outcome i, 0 otherwise. Each crash adds the log of the probability the model gave to what actually happened.

6Maximum likelihood estimation

Estimation means finding the β's that make LL as large as possible. Picture LL as a hill over all possible β values. Software starts somewhere, measures the slope (the gradient, or score), and steps uphill until the ground is flat. Newton-type methods (for example BFGS) also use the curvature to take smarter steps.

  • The estimate is the top of the hill.
  • The standard error comes from how sharp the top is. A sharp peak means the data pin β down precisely: small standard error. A flat top means many β values fit almost as well: large standard error.
  • Convergence means the slope is (almost) zero. Check that the software reports convergence; try different starting values for complex models, because the hill can have several bumps.

7Judging and comparing models

Reference values

  • LL(0): all coefficients zero, every outcome equally likely. With I outcomes and N crashes, LL(0) = N ln(1/I). For N = 2,500 and three outcomes: 2,500 × ln(1/3) = 2,500 × (−1.0986) = −2,746.5.
  • LL(c): constants only.
  • LL(β): the full model at convergence.

Measures

ρ² = 1 − LL(β) ÷ LL(0)  ·  AIC = 2K − 2LL(β)  ·  BIC = K ln N − 2LL(β)K = number of estimated parameters. For AIC and BIC, smaller is better. ρ² (McFadden's pseudo R²) of 0.1–0.3 is common and is not comparable with a regression R².

Worked (invented MNL): K = 12, LL(β) = −2,450.3, N = 2,500.

  1. ρ² = 1 − 2,450.3 ÷ 2,746.5 = 1 − 0.8922 = 0.108.
  2. AIC = 2 × 12 + 2 × 2,450.3 = 24 + 4,900.6 = 4,924.6.
  3. BIC = 12 × ln 2,500 + 4,900.6 = 12 × 7.824 + 4,900.6 = 93.9 + 4,900.6 = 4,994.5.

The likelihood ratio test

A restricted model is an unrestricted model with some parameters locked (usually at zero). The richer model always fits at least as well. The test asks whether the gain is bigger than chance would give.

LR = −2 [LL(restricted) − LL(unrestricted)] ~ χ²(df),   df = number of locked parameters

Worked (coin): restricted p = 0.5 (LL = −6.931), unrestricted p̂ = 0.3 (LL = −6.109), df = 1.

  1. LR = −2 × (−6.931 + 6.109) = −2 × (−0.822) = 1.645.
  2. Critical χ² value at 95% with 1 df = 3.84.
  3. 1.645 < 3.84, so we cannot reject p = 0.5. Ten crashes are too few to tell.
Use the LR test only for nested models estimated on the same data. For non-nested models use AIC or BIC.

8The multinomial logit (MNL)

Each outcome i of crash n has a severity function:

Sin = βiXin + εinβiXin = the explained part (written Vin); εin = everything we cannot see. The outcome with the largest S happens.

If the ε's are independent and identically distributed Gumbel (extreme value type I), the probability of outcome i is (McFadden, 1973):

Pn(i) = eVin ÷ ΣI eVIn

Base outcome. Only differences in V matter, so one outcome (here No injury) has V = 0. Each other outcome's coefficients are read relative to it.

Worked example.

VnoVminorVsevereweights eVtotalP(no, minor, severe)
Belted0−0.5−1.51, 0.6065, 0.22311.82970.547, 0.331, 0.122
Unbelted00.30.11, 1.3499, 1.10523.45500.289, 0.391, 0.320
  1. Unbelted scores: minor −0.5 + 0.8 = 0.3; severe −1.5 + 1.6 = 0.1.
  2. Weights: e0 = 1; e0.3 = 1.3499; e0.1 = 1.1052. Total 3.4550.
  3. P(severe) = 1.1052 ÷ 3.4550 = 0.320. The three shares add to 1.

Limits of the MNL

  • Independence of irrelevant alternatives (IIA). The ratio P(i) ÷ P(j) = eVi − Vj ignores every other outcome. Adding a near-copy of one outcome takes share from all others in proportion, which is unrealistic.
  • Fixed coefficients. Everyone gets the same β. In crash data, many factors that change how a variable acts (body strength, seating position, vehicle details) are not recorded. This unobserved heterogeneity, if ignored, can bias estimates and conclusions (Mannering, Shankar and Bhat, 2016).

9Marginal effects

Coefficients are in log-odds units, which nobody can picture. A marginal effect is a change in probability.

  • For an indicator (0/1) variable: P(outcome | x = 1) − P(outcome | x = 0).
  • For a continuous variable: the change in probability for a small change in x (the derivative).
  • In a study, compute it for every crash and average: the average marginal effect.

Worked (MNL): Unbelted 0 → 1.

  1. No injury: 0.289 − 0.547 = −0.257.
  2. Minor: 0.391 − 0.331 = +0.059.
  3. Severe: 0.320 − 0.122 = +0.198.
  4. Check: −0.257 + 0.059 + 0.198 = 0. Probability is moved between outcomes, not created.
Note: the coefficient of Unbelted in the Minor function is positive (0.8), yet Minor gains only a little: Severe gains more and pulls share away. In an MNL, the marginal effect on an outcome depends on all outcomes' coefficients. That is why papers report marginal effects, not only coefficients.

10Random parameters logit (RPL)

Let the coefficient differ from crash to crash:

βn = β + σ νn,   νn ~ N(0, 1)β = mean effect; σ = standard deviation across crashes; νn = the unseen draw for crash n. Other distributions (lognormal, triangular, uniform) are possible.

We estimate β and σ, not each crash's βn. If σ is not significant, the parameter is treated as fixed.

Worked: what share of crashes have a protective effect? βsevere, unbelted ~ N(1.6, 1.2²).

  1. P(βn < 0) = Φ((0 − 1.6) ÷ 1.2) = Φ(−1.333).
  2. From the normal table: Φ(−1.333) = 0.091.
  3. So in 9.1% of crashes being unbelted lowers the severe-injury score; in 90.9% it raises it.

Why simulation?

The probability is now the MNL probability averaged over the distribution of β:

Pn(i) = ∫ [eVin(β) ÷ ΣI eVIn(β)] f(β | φ) dβ ≈ (1/R) Σr=1..R Pn(i | βr)

There is no formula for this integral. We draw R values of β, compute the MNL probability for each, and average. The resulting simulated log-likelihood is maximised: simulated maximum likelihood. Halton draws (an evenly spread sequence) reach a given accuracy with far fewer draws than random draws; crash studies often use several hundred to a thousand.

Worked: five draws for an unbelted driver, ν = −1.28, −0.52, 0, 0.52, 1.28.

11Heterogeneity in means (RPLHM)

Part of the variation in β may be linked to something we can observe. Let the mean depend on it:

βn = β + Θ Zn + σ νnZn = observed variable(s) for crash n; Θ = the shift in the mean per unit of Z.

Worked. Z = 1 for a young driver, Θ = 0.5.

  1. Mean for young drivers: 1.6 + 0.5 × 1 = 2.1. For others: 1.6.
  2. Spread unchanged: σ = 1.2.
  3. Protective share for young drivers: Φ(−2.1 ÷ 1.2) = Φ(−1.75) = 0.040 (was 0.091).
  4. Average P(severe | unbelted) for young drivers: 0.451 (others: 0.357).

Interpretation. Θ > 0: being young makes the effect of not wearing a belt larger on average. The bell keeps its shape and slides right. Locking Θ = 0 returns the RPL.

12Heterogeneity in means and variances (RPLHMV)

The spread can depend on observed variables too:

βn = β + Θ Zn + σ eω Wn νnWn = observed variable(s) for crash n; ω = their effect on the spread. The exponential keeps the spread positive.

This is the form used by Seraneeprakarn et al. (2017) and many later papers in Analytic Methods in Accident Research.

Worked. W = 1 for a night-time crash, ω = −0.4.

  1. Spread at night: 1.2 × e−0.4 = 1.2 × 0.6703 = 0.804. By day: 1.2.
  2. Protective share at night (not young): Φ(−1.6 ÷ 0.804) = Φ(−1.99) = 0.023.
  3. Young driver at night: mean 2.1, spread 0.804.

Interpretation. ω < 0: at night, crashes are more alike in how much being unbelted matters; ω > 0 would mean more varied. Locking ω = 0 returns the RPLHM.

AIC is lowest for RPLHMV; BIC, which penalises extra parameters more, is lowest for RPLHM. A careful paper reports both and explains its choice (here, the LR tests and AIC favour RPLHMV).

One caution on testing σ = 0: a standard deviation cannot be negative, so the null value sits on the edge of the allowed range and the usual χ² reference is approximate (it tends to be conservative). Practice in the field is still to report the LR test and the t-statistic of σ.

14Workflow for a study

  1. Define the outcomes and code explanatory variables, mostly as 0/1 indicators.
  2. Estimate an MNL; keep variables by a stated rule (for example |t| > 1.96).
  3. Test each coefficient as random (normal first; several hundred to 1,000 Halton draws). Keep it random if σ is significant.
  4. Test observed variables in the means of the random parameters (Θ).
  5. Test observed variables in the variances (ω).
  6. Compare models: LR tests (nested), AIC and BIC.
  7. Report: coefficients with t-statistics; σ, Θ, ω; the share of each random parameter above and below zero; average marginal effects.
  8. Check robustness: more draws, other starting values, other distributions; temporal and spatial stability tests where relevant (see the case study).

Software commonly used for these models includes NLOGIT, Apollo (R) and Biogeme (Python).

15Common mistakes

MistakeWhy it is wrongDo this instead
Reading β as a change in probabilityβ is in log-odds and depends on other outcomes in an MNLReport marginal effects
Comparing LL across different data setsLL grows with N and depends on the dataCompare only models estimated on the same crashes
LR test for non-nested modelsThe χ² result needs nestingUse AIC or BIC
Too few drawsSimulation error can change estimatesIncrease R until estimates stop moving
Predicting with the mean β onlyIgnores the spread (0.320 vs 0.357)Average over draws
"Θ is significant, so Z causes it"It is an association, possibly confoundedDescribe it as heterogeneity linked to Z
Confusing σ with a standard errorσ is real variation across crashes; the standard error is uncertainty about an estimateReport both, clearly labelled

16Glossary

Base outcomeThe outcome whose score is fixed at 0; others are read relative to it.
Coefficient (parameter), βEffect of a variable on an outcome's score.
Gumbel distributionExtreme value type I; the error distribution that produces the logit formula.
Halton drawsAn evenly spread sequence used instead of random numbers in simulation.
Heterogeneity in meansThe mean of a random parameter depends on observed variables (Θ).
Heterogeneity in variancesThe spread of a random parameter depends on observed variables (ω).
IIAIndependence of irrelevant alternatives: the ratio of two probabilities ignores other outcomes.
Likelihood, LProbability of the observed data, viewed as a function of the parameters.
Log-likelihood, LLln L; a sum over observations; closer to zero is better.
LR test−2[LL(restricted) − LL(unrestricted)] compared with χ².
Marginal effectChange in an outcome's probability when a variable changes.
Maximum likelihoodChoosing parameters that maximise LL.
Nested modelsOne model is the other with some parameters locked.
Random parameterA coefficient that varies across observations according to a distribution.
ρ²McFadden's pseudo R²: 1 − LL(β)/LL(0).
Simulated maximum likelihoodMaximum likelihood with probabilities approximated by averaging over draws.
Unobserved heterogeneityVariation in the effects of variables across observations, caused by factors not in the data.

17Formula sheet

Odds and logit

odds = p/(1 − p); z = ln(odds); p = 1/(1 + e−z)

Likelihood

L = Π Pn(observed); LL = Σ ln Pn(observed)

Fit

LL(0) = N ln(1/I); ρ² = 1 − LL(β)/LL(0); AIC = 2K − 2LL; BIC = K ln N − 2LL

LR test

LR = −2[LLR − LLU] ~ χ²(df). χ²0.95: 1 df 3.84 · 2 df 5.99 · 3 df 7.81 · 4 df 9.49

MNL

18Remembering it

The jelly on the table. Picture a long table. On the left, a single toothpick stands upright at 1.6: that is the MNL, one value for everyone. Next to it, someone drops a wobbly jelly: it spreads out from about −1 to 4, and a little red puddle drips past zero, the 9% protective share. That is the RPL and its σ. A group of young drivers walks up and pushes the jelly half a step to the right without changing its shape: the shift Θ, heterogeneity in the mean (RPLHM). Then the lights go out for night and the jelly shivers and pulls itself narrower: the stretch ω, heterogeneity in the variance (RPLHMV).
The judge with a log book. Every model stands in front of a judge who reads each crash and writes down the log of the probability the model gave to what really happened. The total in the log book is the log-likelihood. Closer to zero wins. When a richer model asks for more parameters, the judge doubles the difference in the totals and holds it against a χ² ruler: past the line, the extra parameters are allowed.

19Self-test with answers

  1. A score is z = −1. What is the probability?
    Answer1/(1 + e1) = 1/3.718 = 0.269.
  2. What are the odds when p = 0.8?
    Answer0.8/0.2 = 4.
  3. Twenty crashes, four severe. LL at p = 0.2?
    Answer4 ln 0.2 + 16 ln 0.8 = −6.438 − 3.570 = −10.008. Since 4/20 = 0.2, this is the maximum.
  4. Scores (0, 1, −1) for (no, minor, severe). The three probabilities?
    AnswerWeights 1, 2.718, 0.368; total 4.086; P = 0.245, 0.665, 0.090.
  5. LL(0) = −1,000 and LL(β) = −850. ρ²? AIC if K = 10?
    Answerρ² = 1 − 850/1,000 = 0.15. AIC = 20 + 1,700 = 1,720.
  6. Restricted LL = −1,210, unrestricted LL = −1,200, 3 restrictions. Decision?
    AnswerLR = 20 > 7.81: reject the restrictions; keep the unrestricted model.
  7. A random parameter has mean 0.5 and standard deviation 1. Share below zero?
    AnswerΦ(−0.5) = 0.309, about 31%.
  8. βn = −0.8 + 0.6Z + 1.0ν. Mean when Z = 1?
    Answer−0.8 + 0.6 = −0.2.
  9. σ = 0.9, ω = 0.5, W = 1. The spread?
    Answer0.9 × e0.5 = 0.9 × 1.649 = 1.484.
  10. Four draws give probabilities 0.2, 0.3, 0.4, 0.5. Simulated probability?
    Answer(0.2 + 0.3 + 0.4 + 0.5)/4 = 0.35.
  11. P(severe) goes from 0.15 to 0.27 when a 0/1 variable switches on. Marginal effect?
    Answer+0.12 (12 percentage points).
  12. Which restriction turns RPLHMV into RPLHM? And RPL into MNL?
    Answerω = 0; σ = 0.
